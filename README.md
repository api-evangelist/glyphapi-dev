Glyph encodes content into the cheapest form the reading model can actually parse — a dense learned-font image where it wins, plain text where it doesn't — with honest per-reader token math on every response. It offers a trial key with 20 free calls and pricing at $0.01 per call, targeting AI agents needing cost‑effective context encoding.

**Areas:** AI · Language · Encoding · Pricing · Trial

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Glyph: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
